Step 2: Google Cloud SetupGo to the Google Cloud Console.Create a new project or select an existing one.Enable the following APIs:Admin SDK APIGoogle Workspace Audit APICreate OAuth2 credentials:Navigate to APIs & Services > Credentials.Click Create Credentials > OAuth client ID.Select Desktop app.Download the JSON file, rename it to credentials.json, and place it in the GLAR root directory.Configure Domain-wide Delegation:Go to the Google Workspace Admin Console.Navigate to Security > API Controls > Manage Domain-wide Delegation.Click Add new and enter your OAuth2 Client ID.Add these scopes:https://www.googleapis.com/auth/admin.reports.audit.readonlyhttps://www.googleapis.com/auth/admin.reports.usage.readonlyUsageRun the ScriptBashpython GLAR_Complete_v9.py
